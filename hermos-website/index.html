Questions & Answers

Frequently Asked Questions

Everything you need to know about privacy, local models, and open source licensing.

Is HermOS really 100% free and open source? +
Yes. HermOS is MIT-licensed open source software with no subscriptions, paywalls, or gated "Pro" tiers. All code is public on GitHub. You can inspect the source, audit the security model, and build it locally.
How does HermOS protect my code and privacy? +
HermOS operates with zero telemetry and has no login servers. AI requests route directly from your workstation to your chosen model provider via direct HTTPS using your local API key. Your code never passes through intermediate servers.
Can I use local LLMs like Ollama without an internet connection? +
Yes. HermOS natively connects to local inference runtimes including Ollama, vLLM, and LM Studio. When paired with local models (e.g. Qwen 2.5 Coder, DeepSeek R1, Llama 3.3), HermOS functions 100% offline and air-gapped with zero internet connectivity required.
How are API keys secured on my workstation? +
API keys are encrypted locally with AES-256-GCM. The encryption key is generated per install on your machine and never leaves your device. They are decrypted in memory only when issuing direct requests to model APIs.
How do autonomous subagents work in HermOS? +
HermOS can spawn background worker subagents that operate concurrently across different task domains. Subagents run in isolated workspace worktrees, allowing them to research codebases, run unit tests, and inspect browser DOM nodes without blocking your active editor.
Where can I report bugs or suggest features? +
HermOS is developed in the open. Bug reports and feature requests go to GitHub Issues, and architectural discussions happen in GitHub Discussions.
